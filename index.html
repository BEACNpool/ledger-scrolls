What the evidence tells you

Stored publicly on Cardano. Reconstructed here. The checks have specific limits.

Verify, don’t trust

The reader computes SHA-256 locally and compares it with a declared fingerprint when available. A mismatch blocks rendering. Without a commitment, the file is explicitly unverified. A match proves byte consistency; it does not establish authorship, factual truth, or independent chain inclusion. HTML is sandboxed with scripts and network access blocked.

One work, different storage formats

  • Lock — the whole file in one unspendable UTxO datum; retained while the Cardano ledger retains that output.
  • Chain — larger files, as bare metadata transactions listed by a locked manifest. spec
  • Pages — the original CIP-25 page NFTs (the Bible, the Constitutions); read forever, superseded for writing.

Preserve, then invite responses

A guestbook can permanently name a work and its fingerprint. Entries are public transactions; a name typed into an entry is not identity proof. Long-term access depends on Cardano and available history providers. The open protocol is documented in the repository — minting tools, spec, conformance vectors. Start by minting a scroll — price your file, learn how it works, and mint it right from your browser — see which media types work, read the tutorial scroll above (it lives on-chain), or launch a publisher channel like BEACN Leaks — a byline nobody can forge.
